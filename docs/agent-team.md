# 电影制作 Agent 协作设计

## 总 Agent 的职责

总 Agent 管理已确认创意、剧本、资产版本、分镜、模型任务和审查报告。岗位分工不等于多个模型投票；出现冲突时先遵守用户约束，再由导演协调艺术取舍，由执行制片核查接口能力。尚未确认的探索发型、服装和道具结构不能直接用于生成。

## 部门和交接

| 阶段 | 负责岗位 | 输出与接收方 |
| --- | --- | --- |
| 创意澄清 | 创意开发、总制片 | 动态歧义问题、约束与简报 → 编剧 |
| 剧本 | 编剧、导演、声音指导 | 场次、逐字对白、动作节拍和时长 → 用户确认 |
| 资产 | 美术指导、人物美术、场景美术、道具美术、特效指导 | 逐资产设定板、唯一结构、视觉规范 → 用户确认 |
| 镜头设计 | 导演、分镜导演、摄影指导、动作指导、声音指导 | 分镜、机位路径、动作分拍、对白分配 → 场记 |
| 连续性 | 场记、摄影、动作、道具、剪辑 | 前后依据、明确冲突和待复核项 → 对应责任岗位 |
| 提示词 | 摄影、执行制片 | 模型可执行参数、引用顺序和能力检查 → 用户确认 |
| 执行 | 执行制片 | 持久化任务 ID、队列、结果 → 审片 |
| 质量审查 | 审片、场记、特效 | 实际素材证据、人工复核或有上限的返工 → 生成或设计岗位 |
| 组装 | 剪辑、声音指导 | 时间轴、混音和合成方案 → 最终验收 |

“视觉效果”和“视觉特效”统一为特效指导，涵盖雨水、反射、遮挡与合成；声音指导涵盖对白、音效、环境声与音乐。后续项目复杂时再拆灯光、服装、拟音等子部门，避免空岗位增加调用量。

## 报告契约和状态

独立部门调用读取同一作品版本，报告包含 `roleId / revision / mode / summary / findings`。每条 finding 包含镜头 ID（全局项为空）、严重程度、证据、建议和返工岗位。未知镜头、未知岗位及缺失证据拒绝写入。

只有与作品当前 revision 相同的报告可作为当前意见；修改内容后旧报告仍保留但标为过期。部门报告不自动修改作品、不构成用户批准、不自动触发付费生成。模型文字意见不是已验证的画面事实。

返工建议指向责任岗位，例如：对白超时 → 编剧/声音/总制片；换手不连续 → 动作指导；门窗错位 → 场景美术；接口 404 → 执行制片；画面穿帮 → 需真实视觉证据的质量审查。

## 当前实现范围

- 17 个岗位在 `lib/studio/team.ts` 注册；现有阶段提示词自动包含相关部门责任。
- “制作团队”提供每岗位独立模型会审，结果保存到作品，允许后续岗位读取当前版本报告。
- 分镜导演读取当前部门报告；报告建议需通过现有编辑和确认流程落实。
- 总流程由状态图和人工确认控制。制作团队的“总 Agent 自动协作”可按当前状态选择启用岗位，执行会审、自动修订分镜、编写剧本或新增资产设计候选；每次最多 4 步，每步最多 2 次语言模型调用。仅在面板打开时推进下一步，不是后台常驻进程。
- 自动视觉检测依赖多模态审查网关；声音岗位目前输出方案，不意味着 TTS、SFX、BGM 已生成。
- MiniMax H3 已适配原生 V2 提交与查询，使用本镜头画面作为首帧；不混用首帧模式和参考素材模式。默认 768P，H3 支持 4–15 整数秒，H3-Max 支持 5–15 整数秒。

## 验收

优先检查可验证结果：场次时长合计、对白原文、资产类型和引用、任务持久化及重复提交保护。艺术判断提供证据和取舍，不能用报告数量或虚构分数代替质量。任何真实生成的最终质量仍需实际素材审查。

## 自动协作的修改边界

总 Agent 只能选择白名单文本操作，不提供图片、视频、队列或用户批准工具。自定义岗位模型用于对应任务调用。每步修改在副本中执行，校验通过后原子保存；失败保留原内容。修改前完整备份保存在 `.studio/auto-backups`。剧本更新归档旧版并返回人工确认；分镜修改使下游素材失效。资产设计仅新增候选，须人工选择。步骤之间可停止；离开面板暂停后续推进，但已发出的请求仍会完成。演示模式只演示会审与停止，不伪装真实模型修订。

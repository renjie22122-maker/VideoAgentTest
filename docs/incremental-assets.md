# 增量资产与生成依赖

资产库贯穿制作全过程。角色与场景页提供「快速补充一个资产」和「从最新分镜查漏补缺」；其他阶段可点击「补充 / 调整参考资产」进入。新候选仅追加，不重建全库，不自动调用图像或视频服务。手动补充不调用语言模型；自动查漏补缺调用语言模型，支持没有新增项的结果。

- 不可或缺（required）：需固定身份、造型或关键结构的参考。缺已确认主图时，只阻止涉及场次或显式引用它的镜头提交媒体生成；文字分镜和提示词编译可继续。
- 建议增加（recommended）：有参考图更稳定；缺图时将文字设计和全片风格传入生成，不阻断。
- 可选（optional）：补充细节、一次性装饰或探索。缺图不阻断。

用户可以修改等级与适用场次。旧记录未声明等级时，人物默认不可或缺，场景和道具默认建议增加；旧记录继续按姓名、镜头描述和剧本场次匹配。用户选择全片意味着所有镜头可能使用该参考；指定场次缩小依赖范围。显式手动选择参考图优先于场次范围。缺少结构化场次的旧作品保守保留人物、环境参考。

准备状态按实体 family 和当前选用服装计算。同一实体的新候选与可选细节不重复计为缺失资产。已批准主图即可用于制作；整套一致性审核和独立细节视角为可选完善项。服装仍需明确选用。

生成后替换资产会保留文本分镜、剧本与生成批准，仅归档关联镜头、共享联合片段及同场参考帧接续依赖的旧媒体；不相关镜头和其恢复任务保留，用户上传的首帧保留。旧任务输出链接和替换前完整作品备份用于追溯。若关联任务提交结果未知或远端结果未收回，先恢复查询再换图，不能用换图绕过重复计费保护。新增文字候选或改等级不会重写已有片段。

图像 / 视频供应商的最低输入要求仍然有效：参考图模式需要有效参考图；首帧模式需要首帧；首尾帧模式需要两帧。没有任何图片时，请使用支持文字生成的模式。fal 分镜图在没有参考图时使用文生图。等级表示参考图的制作要求，不证明已生成内容视觉一致，也不允许删去已确认剧情。

实现集中在 asset-policy（等级、匹配与就绪查询）和 asset-catalog（追加、来源及关联素材处理）。用户补充的外观可作为明确来源；模型新增资产必须引用剧本、美术设定或镜头中的原文。每次替换参考版本仍需用户确认，不自动生图或视频。

建立下一幕会继承已确认主图及其身份元数据，并重新按新幕的剧本匹配场次；不沿用上一幕的场次编号范围。自动新增文字候选后继续文字协作，不要求当场生成参考图。

协作期间，“检查衔接”、左侧“连续性检查”、制作步骤回看和镜头查看均保持可用。报告显示最近已保存版本，每步完成后更新；编辑和提交修改仍锁定。

# 专业制作与诊断使用指南

工作台先把创意转成可核对的制作方案，再把方案交给图像和视频模型。制作诊断检查已保存的剧本、分镜、运镜和声音资料；它不是对生成视频的观看、物理模拟或成片评分。

## 从哪里开始

1. 打开作品，在设置以外的工作台页面展开 **制作诊断**。查看问题、依据、负责岗位和建议；“查看 shot-…”可定位对应镜头。
2. 初次使用选 **标准 · 优先确定错误**。旧作品先选兼容模式；想补齐分拍、尺度和声音设计时选 **深入 · 补查设计资料**。
3. 阅读具体依据后勾选要处理的镜头问题，点击 **修订所选问题并复核（语言模型计费，不生成媒体）**，一次最多 20 项。无需为一次局部修订重新生成全部图片或视频。
4. 分镜导演提交修改后，由另一岗位复核。查看实际结果与剩余问题，再确认是否重新编译和生成。剧本原文、整体时长等全局问题应返回对应步骤处理，不能靠偷偷改写分镜绕开。

自动修订需要已确认剧本、现有分镜和真实语言模型配置。演示模式可以查看诊断与手动调整；正在运行的协作结束或停止后，才能启动另一轮修改。

## 三类诊断的意义

| 页面标记 | 表示什么 | 怎么处理 |
| --- | --- | --- |
| 需修正 | 确定的资料冲突，例如不存在的场次引用、台词漏字重说、对白时间窗超出镜长、叙事线接错前镜 | 核对证据，修正资料或回到上游重新确认。新分镜不能把确定冲突留给生成模型自行猜测。 |
| 待复核 | 需要创作判断的风险，例如动作次序、快运镜、轴线换侧、可疑的跨线状态继承、对白可能过密 | 判断是否有剧情、空间或表演依据。有意的设计可以保留并说明，不要求把所有镜头改成固定、缓慢或顺序剪辑。 |
| 资料提示 | 尚未记录对应的结构化信息，常见于旧作品 | 按需要补齐。没有填写物理约束，不等于已经看到画面穿帮。 |

检查深度改变缺失资料的提示程度，不改变已有剧情。深入模式会把缺少设计资料列为待复核，便于选择补齐；它不会因为镜头运动快或世界观包含超常能力就认定错误。

“当前规则未发现问题”表示这组规则没有找到冲突。仍需导演内容评审、实际素材审查和最终试听，不能据此跳过验收。

## 先明确叙事，再设计视听表达

**叙事层**回答谁想做什么、遇到什么阻力、发生了哪些事实、谁说了什么，以及事情为何按这个顺序发生。已确认剧本是依据。

**视听层**决定让观众何时看见信息、采用什么景别和构图、相机为何移动、角色如何表演、在哪里切镜、声音如何先入或延续。一个动作不必机械对应一个镜头；反应镜头和画外声可以共同表达同一事件。

例如，原文是“他握住门把手，听见里面有人说话，于是停下”。可以先拍手部动作，再以画外声和面部反应建立迟疑。不能为了增加镜头变化，擅自变成“他推门闯入”，或把声音安排在作出决定之后却仍宣称保留了原因。

分镜中的“叙事 · 视听 · 物理约束”应能说明动作来源、表达目的、切镜依据、运动动机、速度设计与动作节拍。摄影机速度与人物动作速度分别安排；固定观察、快速跟随或有意越轴都需要相应理由。

## 不同制作层需要什么资料

| 制作层 | 你可以补充的关键输入 | Agent 应交出的可核对结果 |
| --- | --- | --- |
| 故事与下一幕 | 固定身份、世界规则、不可改写的事实；本幕实际结尾的时间、位置、持物、伤势与未解决事件 | 新幕创意分析、承接依据、固定资产引用与需要澄清的变化 |
| 平行叙事 | 哪些事件同时发生、哪些是先后或回忆；切换的戏剧目的 | 每条线的稳定身份、本线最近前镜、经过时间、切回空间线索和声音归属 |
| 空间与尺度 | 已知人物身高、物体相对大小、门窗与通道关系；不确定的尺寸可以不填 | 每镜尺度参照与依据、构图中的远近关系；未知数据不伪装成实测值 |
| 动作与物理 | 特殊动作、道具结构、既定超常能力或必须保持的状态 | 接触、支撑、持握、交接、受力、惯性、遮挡与物体恒常性约束，以及有依据的例外 |
| 对白与表演 | 已确认台词、人物说话习惯、语气意图、对象；特别的口音或音色要求 | 原文分段、说话人、镜内时间窗、画内或画外声、语气、语速、重音、停顿与呼吸 |
| 环境声与后期声音 | 特定声源、静默要求、音乐作用、声音提前或延续的意图 | 分开的环境声、拟音、效果和配乐设计，标出来源空间、时间窗、声桥与混音要求 |

普通物理常识不需要用户逐条写进创意。Agent 有默认约束，并按本镜动作补充具体风险。用户重点补充作品的特殊规则和不可猜测的信息，例如“左手不能负重”“这把枪只有一个弹匣”“龙能悬浮，但鳞片和肢体数量不改变”。

## 同一故事继续拍下一幕

展开 **同一故事 · 第 N 幕 · 连续性资料与下一幕**：

1. 保存固定事实、全故事视听语言、尺度与物理规则。
2. 在“本幕实际交接”写入最终采用的状态。生成画面如果与文字有差异，以你确认的实际状态交接，不依赖 Agent 猜测。
3. 输入下一幕的新事件，点击 **创建下一幕，继承故事资料和已批准资产（不生成）**。
4. 新幕先做创意分析，核对时间推进、人物目标与必要的新资产，再继续剧本和分镜。

每幕独立保存，后续修改不自动覆盖前幕。继承的是故事资料、已批准资产及前幕文字快照；快照不是实际视频分析结果。未批准候选不应被当成固定造型。远端素材引用能否继续读取仍取决于原地址是否有效。

## 交叉剪辑时，每条线各自接戏

A1 → B1 → A2 的播放顺序中，A2 应对照 A1 的人物、服装、道具持有人、动作阶段与空间关系。切到 B 线不等于 A 线自动重置，也不代表 A 已经完成了画外动作。

逐线说明离开期间经过了多少故事时间；“稍后”可以产生合理变化，“连续”需要接上动作。切回来通过地标、人物位置、视线或声音重新辨认空间。同一场次也可以有多条叙事线，不能仅因为播放顺序与剧本文字顺序不同就判断错误。

声音可以越过画面剪辑：A 线的台词在 B 线画面下继续时，仍属于 A 的说话人和空间，不让 B 的人物错误动嘴，不把 A 的道具、服装或环境声来源复制给 B。

## 台词跨镜与声音层

同一句话使用固定的“来源场次 + 台词编号”。例如“收到，正在过桥。”可以在一个镜头说“收到，”，在后镜继续“正在过桥。”；其他叙事线可以插入，两段合起来仍应完整且只说一次。镜内时间决定播放先后，不能只依赖文字列表顺序。

如果同一人物边说话边进入另一个场景，仍可在新画面内说完原句；新场次应登记该人物，并交代进入动作，保留原句来源编号。只有声音跨到另一个空间、本人未在画面中时，才使用相应画外声设计。

表演设计要给可执行要求，例如“前半句克制，停顿后强调‘过桥’，保持自然音量”，并为停顿和呼吸留时间。画外的电话、广播、雨声仍是故事内有声源；它们与叙事外配乐属于不同声音设计。

同一持续声音跨镜保留稳定身份，不同空间和声源分别登记。声音先于下一画面出现、或在切换后继续，都要标明来源和结束位置。对白密度提示只是按语言单位粗估，最终应结合实际朗读、配音或试听判断。

这些要求会进入制作资料和提示词，模型是否执行仍受供应商能力与本次输出影响。独立视频片段不能保证同一音色、连续呼吸、环境底声和波形无缝衔接。需要时按完整台词统一配音，再连续铺环境声与混音；声音岗位写了方案，不代表已经生成或组装了音轨。

## 旧作品怎么补齐

旧分镜继续可读，系统不会伪造一份“已经完成”的专业设计。

- 先在兼容或标准模式查看确定问题，保留已经满意的剧情与素材。
- 再选深入模式，查看缺少动作依据、尺度、物理或声音资料的镜头。选择其中需要升级的项目，让分镜导演补齐并复核。
- 不明确的事实回到故事资料或剧本确认；相对尺度可以有依据地描述，不为通过检查随意填写绝对尺寸。
- 修订提交前保留作品备份，校验失败不覆盖原内容。修订成功会使相关下游素材及生成批准失效，重新确认后再选择需要生成的镜头。

## 看懂自动协作为什么停下

| 状态 | 下一步 |
| --- | --- |
| 运行中 | 当前岗位正在工作或等待下一步；保持工作台打开以推进后续步骤。 |
| 等待你处理 | 查看具体原因。新剧本和资产候选需要你确认，专业部门不能替你批准；也可能仍有需要人工裁决的问题。 |
| 本轮预算已用完 | 本轮调用次数已到上限，查看剩余问题或待复核状态后决定下一轮；预算用完不等于检查通过。 |
| 失败，未应用该步修改 | 查看具体校验或请求错误。原有内容保留，不因看到建议就认定修改已经生效。 |
| 本轮文本任务已完成 | 查看日志中的实际交付与独立复核结论，再进行素材生成和审片。此状态不代表成片已通过质量验收。 |

“停止后续步骤”在当前步骤结束后阻止后续协作；它不撤销已经发出的模型请求。自动协作处理的是文本任务，图片、视频和用户批准仍在相应制作步骤中明确操作。

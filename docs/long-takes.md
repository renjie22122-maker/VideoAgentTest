# 长镜头接续

镜头时长可超过视频供应商的单次上限。当前实现为串行首帧接续，不是供应商原生视频延长接口，不保证视觉无缝。

在分镜编辑器输入 30 秒或更长时长，保持剧本场次总长一致；填写全镜按秒动作计划和对白表演时间窗。重新检查并批准后，先查看本地视频预检，再点击本镜生成。支持已接入的 MiniMax 与 fal Kling；网关仍按自身合同处理。

每段不超过模型上限；提取上一段实际保留画面的最后一帧，为下一段提供首帧。相机按整镜路径采样，段落内对白不重复，分段避开对白时间窗；一条超过单次上限的对白需拆成带停顿的表演条目。只有最终段使用用户尾帧。生成结束后 FFmpeg 统一尺寸、帧率和音频格式，裁去取整余量并拼成一个 MP4，工作台直接播放。

分段按请求次数计费。关闭页面暂停推进，已提交远端任务不一定停止。恢复仅查询已有任务或处理已生成视频；未知提交结果禁止自动重发。供应商明确失败的分段可在预算内重试，已完成段保留。任务中途不能更换模型或供应商。完成后必须人工检查接缝、动作速度、脸部和道具以及声音；没有自动通过视觉审查。音色和配乐可能在分段处变化，需要后期连续音轨时不能依赖逐段原生声音。

本地文件位于 `.studio/videos`，尾帧位于 `.studio/images`，不上传 Git。需要 `@ffmpeg-installer/ffmpeg` 依赖，也可用 `STUDIO_FFMPEG_PATH` 指定本机 FFmpeg；也会查找本工作区 `.studio/runtime/ffmpeg.exe`（Windows）或 `.studio/runtime/ffmpeg`。单次长镜头最多 3600 秒，每段下载限 200 MB。输出归一为 24 fps、横屏 1280×720 / 竖屏 720×1280 / 方形 960×960。不是无损原片交付，原始下载另行保留。

审查修复：预检会提前编译每一段提示词；分段避开已安排的台词。24 fps 帧预算按整镜绝对时间分配，防止逐段舍入累计误差；尾帧使用归一后最后一个实际显示帧，采用原子写入防止中断后使用损坏图片。原声保留，无音轨时才补静音；存在音轨但解码失败时不静默丢弃。

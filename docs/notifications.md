# 模型结果提醒

工作台右上角「完成提醒」可开启或关闭桌面提醒，分别选择语言模型、图片和视频，也可发送不调用模型的测试通知。第一次开启需要用户点击按钮，并在浏览器权限提示中允许通知。页面内的结果提示始终保留。

- 语言模型：创意分析、编剧、美术文字设计、分镜、场记、会审、提示词和剪辑方案保存后提醒；自动协作按实际步骤状态提醒，失败或待确认单独标明。
- 图像：参考资产和分镜画面实际返回后提醒。上传图片、排队或提交成功不会冒充生成完成。
- 视频：片段实际完成后提醒；长镜头等最终拼接输出完成才提醒，不按每一段报整镜完成。素材仍需审查。
- 超时或中断：提示查看请求结果，不自动重新提交或断言供应商未处理。

点击桌面通知或页面提醒的「查看」回到对应作品 / 镜头。未保存草稿或另一作品正在协作时，保留编辑保护。通知正文只包含作品、任务和结果说明，不发送完整提示词或API密钥。

保持工作台标签页打开，可切换工作台页面或最小化。图像和视频共用串行轮询，防止同时查询互相冲突；浏览器休眠、冻结或关闭后不能保证及时收到通知。本功能不增加后台常驻服务，也不改变模型请求超时和重试规则。

通知权限与开关保存在本浏览器中。桌面提醒跨同源标签页去重，页面提示各自显示；刷新不会补发全部历史完成记录。关闭桌面提醒后仍保留页面提示。

Windows 的横幅和通知中心由浏览器及系统设置控制。若测试没有出现横幅，请检查浏览器的网站通知权限、Windows 通知中心和勿扰模式。内置浏览器不支持时，可在 Edge / Chrome 打开同一工作台地址后开启。浏览器要求通知权限请求由用户点击触发，参见 [Notifications API](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API)。

实现分为纯状态差分 notification-events、浏览器传输观察与去重 notification-client、通知界面 NotificationCenter，以及常驻的 MediaPollDriver。通知失败不会改变API调用的成功结果，通知模块不包含生成请求或自动重试功能。

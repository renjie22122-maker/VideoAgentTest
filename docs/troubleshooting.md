# 常见问题与恢复

## 总 Agent 运行时能看检查意见吗？

可以。点击左侧“连续性检查”、分镜页“检查衔接”或已完成步骤，查看最近已保存版本。每步结束后更新；修改内容和再次发起任务仍锁定。当前请求完成后可点击“停止后续协作”。

## Agent 说结束了，批准生成在哪？

总 Agent 结束不是生成批准。查看“下一步 · 生成前确认”的剩余意见；运行本版专业场记检查，再点击“确认检查，编译提示词”。进入提示词页后才显示“批准当前版本，进入生成”。有待裁决意见时，可先填写“我的处理意见（可选）”继续修订。

## 失败，未应用该步修改是什么意思？

该步请求或输出校验失败，没有将这一步的候选修改覆盖作品；此前成功保存的步骤保留。0 步失败表示新一轮还没有成功保存任何步骤，不代表整个作品被清空。查看具体错误，先重新读取保存结果，再决定继续；每轮与修改前完整备份在默认 .studio/auto-backups 目录。

## 分镜后发现新道具，需要回到开头吗？

不需要。点击“补充 / 调整参考资产”，手动快速补充或让 Agent 从分镜查漏补缺。手动补充不调用模型；自动查漏调用语言模型但不生图。不必重建全部资产。

不可或缺主图缺失只阻断相关镜头媒体生成。建议增加、可选缺图可继续，文字设计会进入生成提示词。同一实体的未批准变体、可选细节不会重复算作缺失主图。参考图模式仍需供应商要求的有效图片，纯文字模式也必须由供应商支持。

## 图已生成，但仍显示等待参考图？

先区分“美术资产主图”和“镜头画面”：前者稳定角色、场景与道具，后者是该镜的具体构图 / 首帧。美术图返回后需明确“确认使用”；创建候选或上传本身不代表批准。

在生成前检查里核对当前模式。首帧模式要求本镜首帧，首尾帧模式还需尾帧；文字或美术参考模式不要求另做本镜首帧。查看具体缺失项，不要直接再次付费生成已经返回的图片。

## 超时但供应商已扣费，要重试吗？

超时可能是连接、生成等待或结果取回中断，不能据此认定远端没有处理。先查工作台保存状态和供应商记录；已有远端任务 ID 优先恢复查询。未知提交被保护时，不通过修改分镜、替换参考或重复点击绕过保护。停止本地队列不等于取消远端任务。

本轮正在处理时先等待；读取已保存结果不需要重新调用模型。语言请求可能有多次顺序调用，等待上限与页面关闭行为见 README。通知不会延长超时，也不会自动重发。

## 11.5 秒为什么请求 12 秒？30 秒镜头怎么生成？

分镜保留剪辑时长，模型请求按可支持的整数秒向上取整；余量只保持末状态，后期按原时长裁切。超过单次上限的单镜采用分段接续与最终组装；它仍按多次调用计费，不能保证视觉与声音无缝。见 [长镜头说明](long-takes.md)。

## 已完成的视频在哪里？

在“生成与审片”或该镜的视频区域播放结果。联合生成保留共享结果，不代表自动拆成每个单镜。长镜头最终组装视频默认在 .studio/videos；其他服务可能返回远端 HTTPS 链接，应及时保存。未通过实际审片的素材不能仅凭“已完成”当作最终成片。

## Windows 右下角没有完成提醒？

1. 点击右上角“完成提醒”，开启桌面通知并允许浏览器权限。
2. 确认对应语言 / 图片 / 视频开关已打开，点击“发送测试通知”；测试不调用模型。
3. 检查 Windows 通知中心、通知横幅设置和勿扰模式。权限被阻止时，在地址栏的网站权限中改为允许。
4. 内置浏览器不支持时，在 Edge / Chrome 打开同一个本地工作台地址并重新允许通知。

保持标签页打开，可切到其他工作台页面或最小化；关闭、休眠或冻结后不能保证及时通知。多标签页桌面通知去重，页面提醒各自保留；刷新不会补发全部历史任务。见 [通知说明](notifications.md)。

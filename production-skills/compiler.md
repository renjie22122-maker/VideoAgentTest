# 生成提示词编译 · 2.0.0

将已确认镜头翻译成适合生成任务的具体画面描述，不重新编剧。

- 按“主体与身份 → 环境 → 动作及先后 → 构图 → 运镜 → 光线色彩 → 连续性锚点”编排。用清楚的中文或英文，避免无效的质量词堆叠。
- 每个镜头只描述本镜头的时间范围，保留开始/结束动作状态；不要在一个短片段内要求多个不相容的机位。
- 保留角色服装、关键道具、轴线和运动方向。镜头间复用稳定措辞。
- negative 只针对相关风险；continuityAnchors 列出需沿用的身份、道具、动作和空间约束。
- 不编造供应商参数。未知供应商能力在 capabilityNotes 中列出，不能声称支持精确轨迹、LoRA、首尾帧或参考视频。
- 不提供假 URL。真实参考图及前镜输出由执行节点在提交时注入。

输出 JSON：{shots:[{shotId:string,positive:string,negative:string,continuityAnchors:string[],capabilityNotes:string[]}]}。必须逐一覆盖输入镜头 ID，不能缺漏或增加。


读取 approvedAssetManifest 的名称、类型、版本。fal 路由下，参考图由执行器按当前场次人物和场景筛选，再补充上一镜头；把各参考图的身份与用途讲清楚。画面目标是一个镜头，不得输出角色拼贴或三视图。FLUX Edit 最多 4 图，Seedream 复杂合成最多 10 图，超限必须缩小输入而不能默默截断。OpenAI 当前只有文生图，不能声称已发送输入参考图。

必须携带 intent 中的尺度锚点、动作秒级节拍、速度变化和运镜动机，及 storyContext 的固定设定。参考图按基准身份提取，不复制设定板布局；不得为强化效果改变实体比例。

## 平行叙事与交叉剪辑
- 分开维护播放顺序与各叙事线故事时间。按 threadId 建立状态账本：人物位置、动作阶段、视线/轴线、服装、道具归属与持握、光照和时间。切出不代表状态重置，切回对照本线前镜。
- A1→B1→A2 时，A2 延续 A1；不得套用 B1 的人物、道具、运动方向或环境音。经过时间应明确，允许有依据的省略，不把文字差异自动判为穿帮。
- 每次跨线切换写清戏剧动机（因果、悬念、对照、同时行动等）与空间辨认线索。不得无依据把先后事件表现成同时发生，回忆需要可辨认的时间提示。
- 对白标明说话人与所属场次；J-cut/L-cut 标明声音来自哪条线、提前/延续到何时。声音跨镜不意味着说话人或道具进入另一个空间。
- 视听形式服务原意，禁止为了匹配剪辑制造未获确认的行动或因果。逐线核查动作与对白先后，再核查跨线组合对观众理解的影响。

台词必须继承已确认剧本的说话人、原文、delivery 与动作时序。逐段设计可执行的情绪强度、语速、重音、停顿、呼吸和受话对象，列出镜内秒数。不得通过删除关键对白来满足时长。核对画内口型与画外声源；跨线声桥明确归属，不让另一角色代说。音视频模型是否实际实现这些指令须审片确认，文字约束不等于配音已合格。

声音独立于画面剪辑：对白以来源场次+对白序号保持整句身份，跨镜只分配原文片段，不重新起音或改变音色。区分故事内有源（含画外的人声、雨声、广播）与非故事内声音（配乐、解说等，旁白是否故事内依剧情判断）。环境底声、动作拟音、效果音、配乐独立轨道，写明来源空间、距离、混响和淡变；对白可辨识时压低背景。J/L-cut 和跨线声桥保留原声源，切回不中断仍在持续的声响。独立视频调用不能保证波形连续；后期应按整句录音或连续环境声铺轨，文字方案不等于音频已生成混音。

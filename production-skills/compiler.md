# 生成提示词编译 · 2.0.0

将已确认镜头翻译成适合生成任务的具体画面描述，不重新编剧。

- 按“主体与身份 → 环境 → 动作及先后 → 构图 → 运镜 → 光线色彩 → 连续性锚点”编排。用清楚的中文或英文，避免无效的质量词堆叠。
- 每个镜头只描述本镜头的时间范围，保留开始/结束动作状态；不要在一个短片段内要求多个不相容的机位。
- 保留角色服装、关键道具、轴线和运动方向。镜头间复用稳定措辞。
- negative 只针对相关风险；continuityAnchors 列出需沿用的身份、道具、动作和空间约束。
- 不编造供应商参数。未知供应商能力在 capabilityNotes 中列出，不能声称支持精确轨迹、LoRA、首尾帧或参考视频。
- 不提供假 URL。真实参考图及前镜输出由执行节点在提交时注入。

输出 JSON：{shots:[{shotId:string,positive:string,negative:string,continuityAnchors:string[],capabilityNotes:string[]}]}。必须逐一覆盖输入镜头 ID，不能缺漏或增加。

# 美术与资产连续性 · 2.0.0

输入是确认后的剧本、制作简报与用户约束。输出沿用调用方提供的 bible 字段，不添加不存在的素材 URL。

- character：按人物 ID 和姓名登记身份与关系，区分主角、配角及画外角色。
- appearance：为每位人物给出可复现的轮廓、发型、年龄范围、服装层次、材质与关键配饰；不更改剧本明确的设定。
- location：按场次登记空间布局、出入口、主要物件和人物活动关系。区分同一场景不同时间。
- lighting：记录光源、主光方向、时间连续性，避免只写“电影感”。
- palette：给出主色、辅助色、饱和度和白平衡策略，并与情绪服务关系一致。
- props：逐一登记故事关键道具及其持有人、位置、状态变化，特别是信、手机、食物等影响衔接的物件。
- style：使用摄影/材质/美术的具体描述，不堆砌风格形容词。
- negative：只列与本片相关的角色替换、服装变化、道具闪现等禁止变化。

资产文本是规范，不是已生成参考图。Seed、LoRA 和多参考图是否可用由供应商能力决定，不许声称文本锁定即可保证画面一致。


## 资产设定板执行约定
默认每个人物、场景、道具各生成一张多面板设定板，不能将不同资产合并到同一板。保持逐资产结构化设计，不照搬全量 bible、摄影运镜或场景描述。
人物板：白底或灰底，正侧背全身三视图为主；头部发型探索、仅头部表情组、服装局部方案、面料与鞋子细节为辅。所有分区保持同一身份；基准发型与服装遵循已确认设定，探索方案另区展示，未单独确认不得用于分镜。
场景板：无人空间的全景、反向、入口方向、俯视布局、固定设施与材质细节同板展示。保持门窗、固定家具与通道一致；不镜像代替反向，不编造实测尺寸。
道具板：同一物品正侧背、俯视与关键部件特写；只在真实结构有依据时增加状态。不能混入人物、手持展示、场景或无关道具。
人物与道具使用中性背景与柔光；场景独立提取环境光照。电话或画外角色不自动创建视觉资产。道具按语义实体提取，不按逗号切分。
生成后先确认图片，再人工审核各分区身份、结构、配色及基准方案。整张设定板可独立通过审核，不强制另生成 9/6/5 张图片。可按需从已确认板派生单独视角；这些任务只输出指定视角，保留来源版本。
上传与生成图片都需人工确认。替换基准图使旧派生图失效。服装变更独立建候选并明确选用；设定板中的探索服装不自动成为全片服装。

跨幕优先复用已批准角色身份、服装和道具版本，不因新幕而重新抽取新脸。遵守 storyContext.guide.scaleRules；新状态与物理尺度分开描述，未知绝对尺寸不要编造成原文事实。

# 短片文学剧本 · 2.0.0

依据用户确认的简报与回答创作，不覆盖用户已作出的决定。遵循附加的结构化剧本契约与校验规则。

- 围绕一个核心事件组织有限片长，建立动机、阻力和可见的变化。广告、情绪短片和叙事片采用适合其目的的结构，不强套三幕。
- 用行动、选择、物件和声音表达情绪。对白有角色立场与潜台词，不让人物向观众朗读剧情说明。
- 场次按时间与空间划分；动作和对白必须有先后关系，标记对白所接动作段落。
- 人物目标、事件因果、结尾兑现与生产可行性分别自检。不得通过随意增加角色、地点、闪回解决叙事问题。
- 对用户没有要求的旁白、配乐和字幕保持克制。适当留白，考虑动作与对白的实际时间。
- 返回可编辑的文学剧本，不把文学剧本写成镜头清单。未通过结构校验不得进入资产确认。

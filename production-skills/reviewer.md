# 画面质量与反思审查 · 1.0.0

只有实际读取视频或抽帧后才能给视觉判断；无素材访问能力时交给人工审片。

- 检查人物身份、服装与关键道具、手部与肢体、动作因果、几何稳定、运镜与起止状态。
- 以首/中/尾及动作变化关键帧检查帧间稳定；与前镜末状态比较，不只看漂亮的单张图。
- 审查依据是已确认镜头与设定；不要因为个人审美偏好反复抽卡。
- 退回意见必须指出实际缺陷及其时间位置/画面证据，并给出下一次可以执行的修正；避免“质量不好，请重试”。
- 无法确认的细节明确标为不确定，不假装合格。不输出无依据的数值评分。
- 遵循最大重试次数，超过预算交给用户修改。通过仍需人工确认节奏和艺术取舍。

视觉网关输出遵循现有 {verdict,notes} 契约；notes 中说明证据、修复方向及无法确认的部分。

# FRAME · AI 导演工作台

本地运行的影视创作 Agent：创意澄清 → 结构化剧本 → 美术设定 → 分镜与运镜 → 连续性检查 → 提示词编译 → 图片 / 视频生成 → 审片 → 后期组装。

默认演示模式不需要 API，也不产生模型费用。演示构图卡和动态分镜预演不是写实 AI 影片。真实模式使用用户配置的服务，不会静默回退到演示。

## 快速开始

需要 Node.js 22.13+，建议 Node.js 24。首次安装依赖后启动：

```powershell
pnpm install
pnpm dev
```

已安装依赖时，也可直接启动，无需在 PATH 中找到包管理器：

```powershell
node scripts/start.mjs
```

打开终端给出的本地地址，通常为 http://localhost:3000/。默认只监听本机。通过 **服务与接入 → API 配置** 设置服务、模型和密钥；也可复制空值模板 `.env.example` 到 `.env` 后配置。

界面配置优先于环境变量，保存配置不会调用模型。修改环境变量或服务端模块后需重启本地进程，先等待当前请求结束。当前 API 由 Vite 本地中间件承载，`pnpm start` 仍是本地开发运行时，不能把构建目录当作完整独立服务器部署。

## 最新更新

- **执行底座五件套**：Task-first 全量迁移（每个决策经 提案→任务→调度→Policy→执行 同一链，计划任务带依赖链运行）；SQLite 持久化执行账本（Node ≥ 23.4，旧版自动降级 JSONL）；生成队列提交边界与租约恢复（未知提交永不重发、崩溃后可续查）；Artifact 版本与 current/stale 判定；成本台账与预算摘要。
- **增量资产**：分镜后仍可随时补充人物、场景和道具；手动填写不调用模型，也可让 Agent 从最新分镜查漏补缺。
- **三级依赖**：不可或缺、建议增加、可选。非必要参考图缺失不阻断制作；不可或缺主图只在相关镜头生成前检查。
- **协作中回看**：总 Agent 执行时仍可打开检查衔接、连续性意见、已完成步骤和具体镜头，编辑操作保持锁定。
- **明确交接**：显示本轮实际结果和剩余问题，可填写处理意见继续修订；场记检查、提示词编译和生成批准分别操作。
- **完成提醒**：语言模型结果、图片和视频返回时显示页面提示，可开启 Windows 桌面通知；图片与视频统一跨页面等待。

本次更新详情见 [更新记录](CHANGELOG.md)。

## 推荐制作流程

1. 新建作品，输入创意。目标总时长可自动估算，也可手动设置，最低 4 秒；长故事可分幕制作。
2. 回答针对性的歧义问题，逐条接受、拒绝或修改建议，再确认简报与结构化剧本。
3. 在 **角色与场景** 管理资产文字设计、等级、场次范围及候选图。可先确认文字设定生成分镜，再补图片。
4. 在 **分镜与运镜** 查看动作依据、机位、运动路径、速度、尺度、物理和声音约束。生成图提示词可查看，分镜画面可上传。
5. 点击 **检查衔接** 或左侧 **连续性检查**。展开制作诊断、部门会审和专业场记意见；可按具体问题自动修订，也可填写自己的处理意见。
6. 运行本版专业场记检查，再点击 **确认检查，编译提示词**。在提示词页点击 **批准当前版本，进入生成**。部门会审和总 Agent 停止均不等于已批准生成。
7. 在每镜的视频区域选择输入模式并保存，运行 **生成前检查 / 查看视频提示词**，再单镜、联合或批量生成。图片和视频不会由文本协作自动提交。
8. 播放真实素材、逐镜审查。通过后查看剪辑与声音方案，导出后期时间轴或动态分镜预演；真实片段组装见后期脚本说明。

总 Agent 运行中可回看已保存内容。修改剧本或分镜通常使下游批准与素材失效；确认新资产版本只处理关联媒体依赖，保留文本分镜及生成批准。详情见 [增量资产说明](docs/incremental-assets.md)。

## API 选择与媒体能力

下表描述本仓库已实现的适配范围。模型可用性以用户账户为准，新增供应商不能只替换 URL 就视为兼容。

| 用途 | 已实现选择 | 说明 |
| --- | --- | --- |
| 语言创作 / 会审 | DeepSeek、MiniMax、OpenAI、Claude、Gemini、OpenRouter、Qwen、Ollama、自定义 | OpenAI Chat、Anthropic Messages、Gemini generateContent 三种协议，支持自定义模型 ID |
| 图像 | OpenAI GPT Image、fal FLUX / Seedream、自建网关 | 原生 OpenAI 文生图；fal 支持参考图编辑与分镜合成 |
| 视频 | MiniMax-H3 / H3-Max、fal Kling 3.0 Pro、自建网关 | 输入能力、时长、数量和声音选项由适配器预检 |
| 视觉审片 | 自建 QA 网关或人工 | 只有实际视觉输入才能形成画面审查结论 |

| 视频适配 | 输入方式 | 单次请求与边界 |
| --- | --- | --- |
| MiniMax-H3 | 文字、1–9 张美术参考、首帧、首尾帧 | 4–15 整数秒；支持自选连续分镜联合生成，联合结果暂不自动拆入逐镜组装 |
| MiniMax-H3-Max | 文字、首帧、首尾帧 | 5–15 整数秒；本适配未开放美术参考模式 |
| fal Kling 3.0 Pro | 文字、首帧、首尾帧 | 3–15 整数秒；可选原生声音；本适配未开放美术元素和联合生成 |
| 自建网关 | 首帧及统一媒体合同 | 其他输入能力需在网关与适配器两端实现 |

分镜 11.5 秒可请求 12 秒，剪辑仍保留 11.5 秒；提示词要求余量只保持末状态，不改变对白和动作节拍，计费按供应商生成时长计算。普通片段原文件不会自动裁切，后期脚本按剪辑时长处理。

30 秒或更长的单镜头可通过 MiniMax / fal Kling 串行尾帧接续、断点恢复和 FFmpeg 本地组装实现，单镜上限为 3600 秒；这是多次生成，不是供应商原生延长，也不保证接缝和音色无缝。见 [长镜头说明](docs/long-takes.md)。

Kling 接口资料：[文字视频](https://fal.ai/models/fal-ai/kling-video/v3/pro/text-to-video/api)、[首尾帧视频](https://fal.ai/models/fal-ai/kling-video/v3/pro/image-to-video/api)。新增功能通过模拟响应及本地测试验证，不代表所有服务都已在用户账户收费实测。

## 总 Agent 与用户确认

每轮可选 **4 / 8 / 12 步**，约最多 **8 / 16 / 24 次语言模型调用**。总 Agent 选择启用岗位执行会审、修订分镜、写剧本或新增资产文字候选；没有任意代码执行或自动媒体生成权限。

- 分镜修改后需要另一岗位独立复核。总 Agent 的停止理由不能覆盖实际剩余问题。
- 新剧本需重新确认；美术文字候选可稍后选择，创建候选不会替换已批准参考图，也不暂停文字协作等待生图。
- 可在生成前的 **我的处理意见（可选）** 输入取舍、纠正或补充要求，再继续协作。
- 无实际修改、重复会审、重复候选或修改循环会停止；预算用完保留待复核状态，下轮先复核。
- 每轮与每步均有标识，重复步骤请求返回已保存状态，不重新调用模型。
- 保持工作台标签页打开可跨工作台页面推进；关闭、休眠或冻结后不能保证继续推进。失败时先读取保存结果，不连续重复提交。
- 创作字段在协作期间锁定；可回看报告和镜头，停止入口在当前请求结束后可操作。停止不撤销已发出的供应商请求。

专业规范提高方案的可检查性，不能保证生成结果达到专业成片水平。文本会审、模型返回和素材就绪都不等于画面、声音或表演质量已通过。

## 完成提醒

右上角 **完成提醒 → 开启桌面通知**，在浏览器中允许权限后可发送一条测试通知，不消耗模型额度。可以分别关闭语言、图像或视频的桌面提醒；页面内仍显示结果。

点击提醒返回对应作品或镜头。保持标签页打开，可切换页面或最小化；不支持系统通知的内置浏览器可改用 Edge / Chrome。Windows 横幅受浏览器通知权限、系统通知设置和勿扰模式影响。详见 [结果提醒说明](docs/notifications.md)。

## 本地数据与后期

| 内容 | 默认位置 | 说明 |
| --- | --- | --- |
| 作品与制作状态 | `.studio/projects.json` | 单进程原子文件保存 |
| 执行账本与成本 | `.studio/runtime.db`（或 `.jsonl` 降级） | 运行/任务/生成提交边界/用量，跨进程恢复 |
| API 配置与密钥 | `.studio/api-settings.json`、`.env` | 不进入 Git，不回显密钥 |
| 本地图片与长镜头尾帧 | `.studio/images` | 上传及 OpenAI 生成图等 |
| 长镜头本地视频 | `.studio/videos` | 原始段落和组装结果 |
| 修改前完整备份 | `.studio/auto-backups` | 自动修订、重开协作和替换资产等操作留存 |

可通过 `STUDIO_DATA_DIR` 改变存储目录。fal 等结果可能是供应商临时 HTTPS 链接，重要素材请保存；恢复备份前应先停止所有请求并备份当前作品文件。

`scripts/assemble.py` 使用 FFmpeg 拼接已下载片段及可选已混音音轨。声音岗位输出对白、表演、环境声、音效与配乐设计；视频模型可提供原生声音，但自动 TTS / SFX / BGM 生成、分轨混音、插帧和色彩匹配尚未实现。独立片段的音色连续性不能仅靠提示词保证。

语言模型单次等待上限为 15 分钟，复杂节点包含多个顺序调用；超时不代表供应商未处理或未计费。已知远端任务优先恢复查询，未知提交受保护，不会自动重新提交。当前没有持久后台语言 Worker、多用户鉴权或数据库任务调度。

## 验证与开发

```powershell
node --experimental-strip-types --test tests/*.test.ts
node node_modules/typescript/bin/tsc --noEmit
pnpm lint
node node_modules/vinext/dist/cli.js build
```

测试使用隔离临时作品、模拟供应商响应和本地媒体，不消耗真实模型额度。设置 `REQUIRE_FFMPEG_TEST=1` 可要求 FFmpeg 回归必须执行；本机可用工具路径和组装限制见长镜头说明。

项目目前面向本地单用户制作。多用户权限、后台持久调度、真实画面评测集与完整音频后期需独立设计和验证。

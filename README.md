# FRAME · AI 导演工作台

本地运行的影视创作 Agent：创意澄清 → 结构化剧本 → 美术设定 → 分镜与运镜 → 专业诊断与修订 → 提示词 → 图片/视频队列 → 审片 → 后期方案。

默认演示模式不需要 API，也不产生模型费用。演示的构图卡和无声动态预演不是写实 AI 影片。真实模式始终使用已配置服务，不会静默回退到演示。

## 启动

需要 Node.js 22.13+，建议 Node.js 24。已安装依赖时：

```powershell
node scripts/start.mjs
```

新环境先运行 `pnpm install`，再运行 `pnpm dev`。打开终端给出的地址，通常为 `http://localhost:3000/`。

`pnpm start` 也是本地开发运行时。当前 API 由 Vite 本地中间件承载，不能把 `dist/` 当作完整独立服务器部署。修改服务端模块后需要重启本地进程。

## 这版可以做什么

- 根据创意及已有回答提出针对性问题，区分用户事实、待确认项与创作建议。
- 生成可编辑文学剧本：场次、人物、动作、逐字对白、表演提示及对白动作位置；保留重写历史。
- 分别管理人物、场景、道具、服装和状态候选；可生成或上传参考图，再明确批准版本。
- 逐镜设计表达目的、景别、焦距、机位、动作节拍、运动路径与速度、比例锚点和物理约束。
- 按叙事线追踪前镜状态，支持有依据的平行叙事、跨场声桥和一句台词跨镜延续。
- 免费运行文字与结构预检；按具体问题交给分镜导演修订，再由另一岗位复核。
- 单镜生成、恢复或重新生成；MiniMax-H3 可自选连续分镜联合生成，保留独立结果。
- 同一故事创建下一幕，继承连续性资料、前幕文字快照和已批准美术资产。

专业规范提高可检查性，不保证供应商输出达到专业成片水平；物理一致性、表演与音画质量仍需看真实素材。

## 推荐操作

1. 新建作品，输入创意；时长可选自动估算，也可手动设置。
2. 回答关键歧义，确认制作简报；修改并确认剧本。
3. 在“角色与场景”设计、生成或上传美术图，选择批准版本。
4. 在分镜页查看“叙事 · 视听 · 物理约束”，调整画面、运镜或时长。
5. 打开页面上方 **制作诊断**，查看依据和返工岗位。选择问题后可点击 **修订所选问题并复核**；真实模式会调用语言模型，不自动生成图片或视频。
6. 运行场记语义审查，编译提示词并批准当前版本。
7. 在单镜视频区域保存输入方式，点击 **生成前检查 / 查看视频提示词**；确认模式、时长与参考图后单独或批量生成。
8. 逐镜播放、审片。通过后查看剪辑与声音方案，导出后期时间轴或动态分镜预演。

已完成步骤可回看。内容修改会使相关下游素材及批准失效；自动修订前保存在 `.studio/auto-backups`。旧分镜不会被自动补造专业设计字段，可保留阅读，或在明确选择后由 Agent 修订。

详细说明：[专业制作使用指南](docs/professional-workflow.md)。

## API 选择

通过 **服务与接入 → API 配置** 设置。选择预设、填写账户可用的模型 ID 和密钥，保存立即生效。保存与预检不调用模型。

| 用途 | 已实现选择 | 说明 |
| --- | --- | --- |
| 语言创作/会审 | DeepSeek、MiniMax、OpenAI、Claude、Gemini、OpenRouter、Qwen、Ollama、自定义 | OpenAI Chat、Anthropic Messages、Gemini generateContent 三种协议；自定义模型 ID |
| 图像 | OpenAI GPT Image、fal FLUX/Seedream、自建网关 | 原生 OpenAI 文生图；fal 支持参考图编辑与分镜合成 |
| 视频 | MiniMax-H3/H3-Max、fal Kling 3.0 Pro、自建网关 | 按真实适配能力预检，见下表 |
| 视觉审片 | 自建 QA 网关或人工 | 只有实际视觉输入才能形成画面审查结论 |

| 视频适配 | 输入方式 | 时长与边界 |
| --- | --- | --- |
| MiniMax-H3 | 文字、1–9张美术参考、首帧、首尾帧 | 4–15整数秒；可联合连续镜头，联合结果暂不自动拆分进入逐镜组装 |
| MiniMax-H3-Max | 文字、首帧、首尾帧 | 5–15整数秒；不支持本适配的美术参考模式 |
| fal Kling 3.0 Pro | 文字、首帧、首尾帧 | 3–15整数秒；可选原生声音；当前未开放美术元素及联合生成 |
| 自建网关 | 首帧及统一网关合同 | 更多输入能力须先在网关及适配中实现，不是任意供应商地址都兼容 |

Kling 支持中文/英文原生语音，其实现及限制核对自 [fal 官方文字视频接口](https://fal.ai/models/fal-ai/kling-video/v3/pro/text-to-video/api) 和 [首尾帧接口](https://fal.ai/models/fal-ai/kling-video/v3/pro/image-to-video/api)。新增适配通过模拟响应测试，尚未对用户账户执行收费实测。

语言模型配置、输出预算和扩展方法：[语言服务接入](docs/language-providers.md)。网关协议：[媒体与审查网关](docs/media-gateway.md)。

## 总 Agent 的行为

每轮可选 4 / 8 / 12 步，界面标明约最多模型调用次数。总 Agent 选择岗位与任务；动作合同限制为会审、修订分镜、写剧本、设计文字候选、停止。

- 分镜修改后必须由另一岗位复核；确定性错误未解决不能显示完成。
- 新剧本与美术候选停在等待用户确认；候选不替换原批准版本，不自动生成媒体。
- 无内容变化、重复会审、重复候选或修改循环会停止。
- 预算耗尽保留待复核状态，下轮先复核，不盲目重复修改。
- 每轮和每步有标识；重复步骤请求只返回已保存状态，不重新调用模型。
- 工作台打开时推进，关闭后暂停。请求失败时暂停自动推进，先读取已保存结果，再由用户决定是否继续。
- 自动运行时锁定创作字段，可回看页面；全局提供停止入口。

“文本任务完成”不等于“影片质量通过”。没有真实视频审查的报告不能声称换脸、物理穿帮或音画质量已合格。

## 资料与后期

- 作品：`.studio/projects.json`；密钥：`.studio/api-settings.json`；本地图：`.studio/images`。均不进入 Git。
- 界面配置优先于 `.env`。密钥不回显，不写入作品导出；切换实际服务域名需要重新填写或明确清除对应密钥。
- fal 素材可能是供应商临时 HTTPS 链接，重要结果请自行保存；本地上传与 OpenAI 生成图保存在本机。
- API 请求超时不表示没有处理或计费。已知远端任务只恢复查询；未知提交不会自动重发。停止本地跟踪不等于供应商取消。
- 语言请求等待上限为15分钟，复杂节点的浏览器等待时间包含多个顺序调用；关闭页面后可重新读取已保存结果。尚无持久后台语言任务 Worker。
- 后期时间轴携带对白、表演、声音层和跨镜原句标识。它是声音设计，不是已生成音频。
- `scripts/assemble.py` 可通过本机 FFmpeg 拼接已下载片段及一个已混音音轨；TTS/SFX/BGM 自动生成、分轨混音、插帧和色彩匹配尚未实现。独立生成片段的音色连续性不能仅靠提示词保证。
- 本地数据是单进程文件存储，不适合多服务进程共用同一数据目录。跨幕继承为快照，不宣称与前幕实际成片自动一致。

本版本面向本地单用户工作流。多用户鉴权、数据库任务调度、真实视频评测集和完整音频后期属于后续独立工程工作。

MiniMax 时长适配：例如分镜 11.5 秒，实际请求 12 秒，剪辑仍保留前 11.5 秒。提示词要求尾部只保持末状态，原文件不会自动裁切；后期脚本按原剪辑时长裁切，计费按供应商生成时长计算。该规则不改变对白、动作节拍和全片目标时长。

长镜头：支持 MiniMax / fal Kling 串行尾帧接续、分段恢复和 FFmpeg 本地组装，详见 [长镜头说明](docs/long-takes.md)。接缝与原生声音仍需人工审查，不保证视觉无缝。
